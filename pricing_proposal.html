📋 કાર્યકારી સારાંશ (Executive Summary)

આ AMC સેવા પોર્ટલ અત્યંત આધુનિક અને લાઈટવેઈટ ટેકનોલોજી પર તૈયાર કરવામાં આવેલ છે. મેપિંગ (Leaflet + OpenStreetMap) અને ઓન-સ્ક્રીન વોઇસ સ્પીચ API ૧૦૦% ફ્રી છે. મુખ્ય માસિક રિકરિંગ ખર્ચ માત્ર Meta WhatsApp Cloud API (જે નાગરિકોને કમ્પ્લેઇન્ટ નંબર, ફોટો અને અપડેટ્સ મોકલે છે) અને ક્લાઉડ હોસ્ટિંગ સર્વર પર આધારિત છે. નીચે દરેક સ્તર મુજબ પારદર્શક ગણતરી આપેલ છે.
